# 챕터 1 보스

`Assets/Scenes/보스테스트.unity`를 열고 Play를 누르면 전투가 시작됩니다.
보스는 오른쪽에 고정되고, 왼쪽의 3단 발판에서 공격을 피하며 싸웁니다.

| 패턴 | 가이드 반영 내용 |
| --- | --- |
| 미사일 낙하 | 무작위 위치에 4~7발 발사. 발판·바닥·플레이어에 닿으면 `미사일_16.prefab`으로 폭발합니다. |
| 가로 미사일 | 무작위 높이에서 왼쪽으로 7~10발 발사. 이동 속도는 3입니다. 같은 폭발 프리팹을 사용합니다. |
| 레이저 | `스나이퍼_0.prefab`을 늘려 사용합니다. 빨간 수평선에서 초록 대각선 방향으로 2초 동안 회전하며, 발사 중 무지개 그라데이션을 표시합니다. |
| 원거리 몹 소환 | 인게임샘플의 원본 `플라잉몹_0.prefab` 2마리를 소환합니다. 소환된 플라잉몹이 남아 있으면 재소환하지 않습니다. |

사용 가능한 패턴을 무작위로 고르며, 다른 패턴이 있으면 직전 패턴의 연속 사용을 피합니다.
레이저와 소환에는 예고 표시가 있습니다. 보스나 플레이어가 쓰러지면 진행 중인 공격과 소환 몹을 정리합니다.

## 조작

- A / D: 이동
- W: 점프
- S: 앉기
- 마우스: 조준 / 왼쪽 버튼 사격
- R: 장전

## 다른 씬에 배치

1. `Assets/몬스터/챕터1보스몹/챕터1보스.prefab`을 씬으로 드래그합니다.
2. 보스 루트의 위치를 바닥 높이에 맞춥니다. 루트가 보스 발밑입니다.
3. `BossMonsterController`의 플레이어를 연결합니다. 비워 두면 씬의 `ArisaHealth`를 찾습니다.
4. 보스를 선택하면 표시되는 전투 영역을 확인하고 영역 최소·최대 좌표를 조절합니다. 좌표는 보스 발밑 기준입니다.
5. 바닥은 `Box`, 일방향 발판은 `Stair`, 피격 대상은 `Enemy` 레이어를 사용합니다.

패턴 수치·프리팹은 `Assets/SO/몬스터/챕터1보스패턴SO.asset`, 보스 HP는 `챕터1보스SO.asset`에서 조절합니다.
Inspector의 설정 이름은 한글로 표시됩니다.

테스트 씬은 피해량 1인 `Assets/SO/총/보스테스트기관단총SO.asset`을 사용합니다.
기존 총 SO의 피해량은 그대로 유지하므로, 다른 씬에서도 싸우려면 사용할 총 SO의 데미지를 0보다 크게 설정하세요.
일반 탄환·스나이퍼·샷건은 `MonsterHealth`에 피해를 전달하며, 플레이어 미사일은 기존 폭발 피해를 사용합니다.

에셋을 다시 생성하려면 `Tools > Shotgame > 보스 > 보스 프리팹과 테스트 씬 생성`을 실행합니다.
이 메뉴는 보스 프리팹과 테스트 씬을 재생성합니다. 기존 SO의 수치 조정은 보존합니다.
